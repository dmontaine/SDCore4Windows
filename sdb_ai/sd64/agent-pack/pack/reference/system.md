What `create.account` prints when typed with no arguments:

```
Command Syntax: create.account user <user name> {ssh | api | both | none} {sh-on} {os-on} {voc-on} {bp-on} {dict-on} {net-on} {files-on} {files-write-on} {files-admin-on}
                  {shared-read-off} {shared-write-on} {start-menu | start-terminal} {pins-on} {recovery-on} {no.query}
                  A new user account starts with no ssh, no API, no shell (sh), no os.execute, no right to change
                  the VOC (voc-on), a program file (bp-on) or a dictionary (dict-on), no files on other SD servers
                  (net-on), and no files-only login (files-on; it cannot change files here without files-write-on); it can open and read the files
                  of the shared account by name unless shared-read-off is typed, and cannot write them unless
                  shared-write-on is typed;
                  the words above give them, and modify.account changes any of them afterwards, either way.
                  It starts where the system default says (set.start.default) unless start-menu or start-terminal is typed,
                  and cannot add programs of its own to its home screen unless pins-on is typed.
                  Its editors keep no recovery copy of unsaved text unless recovery-on is typed (a user account only).
                create.account group <group name> {start-menu | start-terminal} {pins-on} {no.query}
                create.account other <account name> <pathname> {start-menu | start-terminal} {pins-on} {no.query}
```

```
Command Syntax:  modify.account <account> add | delete <username>
                  modify.account <account> ssh | api | both | none
                  modify.account <account> sh-on | sh-off
                  modify.account <account> os-on | os-off
                  modify.account <account> sd-on | sd-off
                  modify.account <account> voc-on | voc-off | bp-on | bp-off | dict-on | dict-off
                  modify.account <account> recovery-on | recovery-off
                  modify.account <account> net-on | net-off
                  modify.account <account> files-on | files-off | files-write-on | files-write-off | files-admin-on | files-admin-off
                  modify.account <account> shared-read-on | shared-read-off | shared-write-on | shared-write-off
                  modify.account <account> start-menu | start-terminal | start-default
                  modify.account <account> pins-on | pins-off
                  modify.account <account> suspended | unsuspended
  Any of the actions except add and delete may be given together in one command, for example
                  modify.account <account> sh-on os-on voc-on bp-on
  They are all carried out, in the order of the list above whatever order they were typed, or none is.
```
